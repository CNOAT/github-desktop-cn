# 完整界面翻译对照表

## 一、欢迎页（Let's get started!）

| 英文原文 | 中文翻译 | 备注 |
|------|------|------|
| Let's get started! | 开始使用！ | 大标题 |

| Filter your repositories | 筛选你的仓库 | 搜索框占位文字 |
| Create a tutorial repository... | 创建一个教程仓库... | 蓝色主按钮 |
| Clone a repository from the Internet... | 从网络克隆仓库... | 第二个按钮 |
| Create a New Repository on your local drive... | 在本地磁盘创建新仓库... | 第三个按钮 |
| Add an Existing Repository from your local drive... | 从本地磁盘添加已有仓库... | 第四个按钮 |
| ProTip! | 小技巧！ | 提示标题 |
| You can drag & drop an existing repository folder here to add it to Desktop | 你可以直接拖放已有仓库文件夹到这里来添加 | 提示内容 |
| Looks like there are no repositories for XXX on GitHub.com. Refresh this list if you've created a repository recently. | 看起来 GitHub.com 上没有属于 XXX 的仓库。如果你最近创建了仓库，请刷新此列表。 | 空状态提示 |
